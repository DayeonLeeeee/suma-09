# 시연 화면 점검 (11/3)

발표 QR로 들어오는 시연 페이지(30번 문제)를 휴대폰 화면(390×844) 기준으로 확인한 내용이다.

## 화면 흐름

문제 → 풀이 사진 선택 → 채점 중 → 결과(처음 틀린 줄, 힌트 3단계, 유사 문제 추천) → 해설

- 로그인 없이 바로 문제가 뜬다. 교수님이 QR을 찍자마자 풀어볼 수 있게 하려는 것.
- 시연 페이지는 Supabase에 아무것도 쓰지 않는다. 연구 데이터와 섞이지 않는다.
- 해설은 손글씨 해설과 같은 순서(aaa가 양 끝 → 가운데)로 고정해 두었다. 생성하지 않으니 바로 열린다.

## 고친 것

| 위치 | 전 | 후 | 이유 |
|---|---|---|---|
| 힌트 탭 | 2·3단계를 눌러도 안 열림 | 앞 단계를 본 다음 순서대로 열림, 본 단계는 다시 볼 수 있음 | 기존 코드 버그. 현장연구 힌트 로그 89건이 전부 1단계였던 원인 |
| 잠긴 힌트 탭 | 투명도 40%라 글자가 거의 안 보임 | 55% | 잠겨 있어도 무엇이 있는지는 보여야 함 |
| 결과 화면 줄 표시 | Step 1 · 맞음 | 1번째 줄 · 맞음 / 처음 틀린 줄 | 서비스 핵심 용어(처음 틀린 줄)를 화면에서도 같은 말로 |
| 조건 상자 | "a뿐 / 이다"처럼 단어 중간 줄바꿈 | 단어 단위 줄바꿈 | 시험지처럼 읽히게 |
| 제출 오류 | 브라우저 알림창 | 문제 화면에 빨간 글씨 + 다시 할 일 안내 | 알림창은 휴대폰에서 흐름을 끊음 |
| 화면 확대 | 막혀 있음 | 손가락으로 확대 가능 | 긴 문제를 확대해서 읽을 수 있어야 함 |
| 채점 대기 문구 | (없음) | 사진을 읽고 처음 틀린 줄을 찾는 중입니다 | 걸리는 시간은 재 본 적이 없어서 시간 약속은 쓰지 않음 |

## 유사 문제 추천 카드

오답일 때만 결과 화면 아래에 나온다. 교수님께 알고리즘이 실제로 돌아가는 걸 보여 주려는 용도라 점수까지 그대로 노출했다.

- 무엇을 보여 주나: 틀린 위치(초반·중반·후반)와 오답유형, 추천 문제 본문, 함정 위치·난이도·새로움 점수 막대, 최종 점수 계산식
- 같은 접속에서 같은 유형으로 또 틀리면 목표 난이도가 한 단계 내려간다. 로컬에서 B01로 두 번 틀려 보니 중간 난이도(Q-3) → 기본(Q2-5)으로 바뀌었다.
- "설계 단계" 표시를 붙였다. 문항 태그는 교사 검수 전 임시값이고 효과 검증은 하지 않았기 때문.
- 서버에 `/api/recommend`가 없으면(지금 배포본) 카드가 조용히 빠진다. 결과 화면은 그대로.

## 남은 것 (손대지 않음)

- 상단 "문제"·"결과" 버튼 높이가 36px로 손가락 터치 권장 크기(44px)보다 작다. 기존 화면 전체가 같은 스타일이라 시연 전에는 그대로 둠.
- 추천 문제는 미리보기만 된다. 눌러서 바로 풀게 하려면 추천 문항마다 정답이 있어야 하는데, P2·Q2 세트는 정답 칸이 비어 있다.
- 실제 풀이 사진으로 OCR부터 채점까지 돌려 본 적은 없다(테스트는 가짜 응답). 배포 후 한 번 확인 필요.
